# API Reference

Invex .NET Tools ships command-line tools, not libraries, so there is no API meant for consumers. The only public
type, <xref:Invex.Tools.ArtifactClean.Commands>, is the command plumbing behind `artclean` and may change without notice.

To use the tools, see the [Introduction](../docs/introduction.md) and the [ArtifactClean](../docs/artifactclean.md) command reference.
